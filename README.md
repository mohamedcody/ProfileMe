# 🚀 ProfileMe — Personal Portfolio & Showcase

A modern, responsive, and interactive personal portfolio web application built with **React 19**, **TypeScript**, and **Vite**. Features full bilingual support (Arabic & English), smooth animations, modern UI components, and direct contact integration.

---

## 🌟 Features

- **🌐 Bilingual & RTL Support**: Seamless localization (Arabic / English) using `i18next` with full RTL layout support.
- **✨ Smooth Motion & Transitions**: Powered by `framer-motion` for fluid page transitions and interactive elements.
- **💼 Comprehensive Showcase**:
  - **Home**: Dynamic hero section, services highlight, and featured work.
  - **Projects**: Portfolio gallery with detailed case studies.
  - **Services**: Detailed breakdown of software engineering & development solutions.
  - **Team**: Collaborative team profiles and roles.
  - **Contact**: Direct WhatsApp & Telegram communication channels.
- **⚡ High Performance**: Ultra-fast build and development workflow powered by Vite.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Localization**: [i18next](https://www.i18next.com/) & [react-i18next](https://react.i18next.com/)
- **Linter**: [Oxlint](https://oxc.rs/)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) and `npm` installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mohamedcody/ProfileMe.git
   cd ProfileMe/portfolio-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

### Build for Production

To create an optimized production build:
```bash
npm run build
```
